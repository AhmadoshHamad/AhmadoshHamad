### 🛠️ What I work on

- **Infrastructure as Code:** modular Terraform and Terraform Stacks on HCP Terraform, with Sentinel Policy as Code guarding every plan.
- **AWS:** scalable, highly available infrastructure across multiple accounts: microservices, event-driven and serverless architectures, CI/CD, and cost estimation and optimization.
- **Platform Engineering:** an AI-powered Internal Developer Portal on Backstage, covering the software catalog, self-service actions, integrations, scorecards, data modeling, and ingestion, with MCP.
- **DevSecOps:** SonarQube quality gates and SAST in GitHub Actions CI/CD pipelines.
- **Kubernetes:** microservices and MCP servers (Terraform, SonarQube) with Helm and GitOps.
- **Observability:** Prometheus, Grafana, and Datadog.
- **AI-driven DevOps:** Claude Code agents that turn plain-English infrastructure requests into reviewed Terraform PRs.
